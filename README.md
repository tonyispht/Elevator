# Elevator

A first-person browser game set inside a low-poly elevator. Ride between floors P and 1–9, explore the lobbies, the parking garage, the Leake Street graffiti tunnel, and find the key to apartment 3B.

Play: https://tonyispht.github.io/Elevator/

Controls: WASD / drag to look / click or E to use / Shift to run. Touch: left stick to move (push fully to run), drag to look, USE button.
